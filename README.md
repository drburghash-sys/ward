# وِرد — أذكار ومسبحة

تطبيق عربي للأذكار والمسبحة والورد الشخصي، مصمم كتطبيق ويب تقدمي PWA للعمل على GitHub Pages وعلى الجوال.

## الوظائف
- أذكار الصباح والمساء.
- أذكار ما بعد الصلاة.
- مسبحة 33 / 100 / مخصص / بلا حد.
- تراجع وإعادة ضبط واهتزاز اختياري.
- ورد شخصي مع توضيح أن العدد شخصي.
- مكتبة أذكار ومصادر.
- سجل إنجاز آخر 7 أيام.
- مظهر داكن وفاتح.
- دعم العمل دون اتصال بعد أول فتح.

## النشر
GitHub Pages من فرع main وجذر المستودع.
